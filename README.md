# Кадр — камера с сетками композиции

Веб-приложение для телефона: живая камера, 23 сетки и приёма из гайда
по композиции, подсказка с примером к каждой.

## Что внутри
- `index.html`, `style.css` — экран.
- `js/grids.js` — геометрия всех сеток, тексты подсказок, картинки-примеры.
- `js/app.js` — камера, съёмка, снимки, уровень, разбор фото.
- `sw.js`, `manifest.webmanifest`, `icons/` — работа без интернета и иконка на экране «Домой».
- `examples/` — сюда можно положить свои примеры.

## Свои примеры вместо схем
1. Положи картинку 3:4 в `examples/`, имя = id сетки: `thirds.jpg`, `spiral.jpg`, `dynamic.jpg`…
2. Впиши id в `examples/index.json`, например `["thirds", "spiral"]`.
id сеток: none thirds phi spiral center symmetry dynamic goldtri diagonals leading
triangle radial odd frame foreground negative fill reflection ma horizon portrait dutch safe.

## Как открыть на телефоне
Камера в браузере работает только по ссылке https. Самый простой путь —
бесплатный GitHub Pages. Потом в Safari:
«Поделиться» → «На экран „Домой“».

## Честные ограничения
- Снимок — кадр из видеопотока камеры, не фото штатной камеры iPhone
  (нет ночного режима и Deep Fusion). Разрешение видно в настройках.
- В «Фото» сохраняется через «Поделиться» → «Сохранить изображение».
- Уровень и голландский угол работают от датчика наклона; если линия
  крутится не туда — в настройках «Уровень наоборот».
- Для полного качества: сними обычной камерой → «Разобрать готовое фото».
